# 🔥 Sentiment Analysis Project

## 📌 Overview
This project performs sentiment analysis on text data using Machine Learning.  
It classifies text into Positive, Negative, or Neutral categories.

## 🚀 Features
- Text preprocessing (stopwords removal, stemming)
- TF-IDF vectorization
- Naive Bayes classifier
- Streamlit web app interface

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit

## 📊 Model Accuracy
Achieved classification accuracy using Multinomial Naive Bayes.

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
